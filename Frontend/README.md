## Overview

Truce Wallet is a comprehensive, AI-powered multi-chain wallet and decentralized exchange (DEX) built specifically for the BlockDAG ecosystem. It provides users with a unified platform for storing, swapping, staking cryptocurrencies, and accessing AI-driven trading insights—all within a single, secure, non-custodial application.

**🚀 Now live on BlockDAG Testnet** | **🔗 [View on GitHub](https://github.com/your-username/truce-wallet)**

## System Architecture

```
React Frontend (TypeScript + Tailwind)
    ↓
Web3 Integration (Ethers.js)
    ↓
Smart Contracts (Solidity on BlockDAG)
    ↓
BlockDAG Testnet
    ↓
AI Service (Predictive Analytics)
    ↓
MongoDB Database
```

### Technology Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS, Vite
- **UI Components**: shadcn-ui, Radix UI primitives
- **Web3**: Ethers.js, WalletConnect
- **Blockchain**: Solidity smart contracts on BlockDAG
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **AI/ML**: TensorFlow.js, custom prediction models

## Getting Started

### Prerequisites
- Node.js 18+ and npm
- Modern web browser with Web3 support

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/truce-wallet.git
cd truce-wallet

# Install dependencies
npm install

# Start development server
npm run dev
```

### Building for Production

```bash
# Create production build
npm run build

# Preview production build
npm run preview
```
